# GenUI — camada gráfica inicial

A primeira implementação de GenUI é desenhada diretamente no framebuffer solicitado ao bootloader Limine pelo GenKernel. Ela apresenta uma área de trabalho, painel inferior e janela informativa. Nesta etapa ainda não existe compositor, eventos de mouse/teclado, janelas móveis, fonte completa ou processos em modo usuário. Esses itens estão planejados para etapas posteriores.
